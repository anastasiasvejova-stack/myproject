# Ежедневник

## Программа для создания заметок, написанная на  библиотеке **QT** .

### В программе существует следующий интерфейс: создание записей, сохранение их под определенную категорию, создание 
### уведомлений.
- Этот проект представляет собой простое приложение настольного календаря (планировщика задач), 
разработанное на Python с использованием библиотеки PyQt6 для создания графического интерфейса 
и SQLite для постоянного хранения данных.
# Описание проекта
- Простое приложение-дневник
#### Описание функционала
Приложение предоставляет пользователю базовый функционал для управления личными записями и событиями:
1. благодаря простому интерфейсу вы легко можете пользоваться своими заметками
2. в это вам также поможет подразделение на категории, так что вы сможете определить актуальные задачи для выполнения
3. а уведомления не дадут забыть о ваших планах
##### Использованные виджеты
1. Используется виджет QCalendar для выбора даты
2. Также QPushButton в виде кнопок
Что еще надо знать:
- Python: Язык программирования.
- PyQt6: Фреймворк для создания графических пользовательских интерфейсов (GUI).
- SQLite3: Легковесная встраиваемая система управления базами данных.
- Qt Designer (.ui): Интерфейс приложения описывается в строковом XML-шаблоне, 
который динамически загружается с помощью uic.loadUi.
###### Запуск проекта
1. Для запуска проекта необходимо установить библиотеку PyQt6 (pip install PyQt6) и запустить файл Python. 
2. Вместе с файлом автоматически будет создан файл базы данных diary.db.
